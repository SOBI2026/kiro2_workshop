# 워크플로우 테스트 시나리오

## 현재 상태
- 낙상 감지됨 (accelerometer: 15.8)
- 알림 생성됨 (status: voice_confirmation_pending)

## 테스트 순서

### 1단계: 대시보드 확인
1. 브라우저에서 http://localhost:8504 접속
2. "실시간 워크플로우 상태" 섹션 확인:
   - 1단계: ✅ 정상 (초록색)
   - 2단계: ⚠️ 경고 (빨간색) - 낙상 감지!
   - 3단계: ⏳ 진행중 (주황색) - 음성 확인 중
   - 4단계: ⏸️ 대기 (회색)

### 2단계: 음성 응답 시뮬레이션

#### 시나리오 A: 정상 응답
1. "✅ 정상 응답 (안전)" 버튼 클릭
2. 페이지 새로고침 (F5)
3. 3단계가 ✔️ 완료 (초록색)로 변경됨
4. 4단계는 여전히 ⏸️ 대기 (알림 불필요)

#### 시나리오 B: 응답 없음 (위급)
1. "⚠️ 응답 없음 (위급)" 버튼 클릭
2. 페이지 새로고침 (F5)
3. 3단계가 ⚠️ 경고로 변경됨
4. 4단계가 활성화됨

### 3단계: 보호자 알림 발송
1. "📤 긴급 알림 발송" 버튼 클릭
2. 긴급 알림 메시지 확인:
   ```
   🚨 긴급 알림
   
   김영희님(75세)에게 이상 징후가 감지되었습니다.
   
   - 낙상 의심 (가속도: 15.8)
   - 음성 응답 없음
   - 즉시 확인이 필요합니다
   ```
3. SMS 및 푸시 알림 발송 확인

### 4단계: 상황 종료
1. "✔️ 상황 종료" 버튼 클릭
2. 페이지 새로고침 (F5)
3. 모든 단계가 정상 상태로 복귀

### 5단계: 새 시나리오 테스트
1. "🔄 워크플로우 초기화" 버튼 클릭
2. 모든 알림 삭제됨
3. "🚨 새 낙상 시나리오 실행" 버튼 클릭
4. 터미널에서 `python dashboard/run_scenario.py` 실행
5. 1단계부터 다시 테스트

## 실시간 상태 변화

### 정상 상태
```
1. 센서 데이터 수집: ✅ 정상 (초록)
2. 활동 부재 감지: ✅ 정상 (초록)
3. AI 스피커 음성: ⏸️ 대기 (회색)
4. 보호자 알림: ⏸️ 대기 (회색)
```

### 낙상 감지 후
```
1. 센서 데이터 수집: ✅ 정상 (초록)
2. 활동 부재 감지: ⚠️ 경고 (빨강) - 낙상!
3. AI 스피커 음성: ⏳ 진행중 (주황) - 확인 중
4. 보호자 알림: ⏸️ 대기 (회색)
```

### 음성 응답 없음
```

3. AI 스피커 음성: ⚠️ 경고 (빨강) - 응답 없음
4. 보호자 알림: ⚠️ 경고 (빨강) - 발송 필요
```

### 알림 발송 후

```
3. AI 스피커 음성: ⚠️ 경고 (빨강)
4. 보호자 알림: ✔️ 완료 (초록) - 발송 완료
```

### 상황 종료 후
