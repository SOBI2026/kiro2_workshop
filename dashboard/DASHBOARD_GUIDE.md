# 시니어 안심 케어 - 대시보드 가이드

## 개요

시니어 안심 케어 시스템은 3가지 대시보드로 구성되어 있으며, 각각 다른 역할과 목적을 가지고 있습니다.

---

## 🔧 대시보드 1: 백엔드/관리자용 (포트 8503)

### 역할
시스템 설정 및 관리를 위한 백엔드 대시보드

### 주요 기능
1. **보호자 연락처 설정** ⭐ 중요!
   - 보호자 이름, 관계, 휴대폰 번호, 이메일 설정
   - DynamoDB UserSettings 테이블에 저장
   - **대시보드 3에서 이 정보를 자동으로 읽어서 사용**

2. **센서 데이터 전송**
   - 수동으로 센서 데이터 전송 (테스트용)
   - DynamoDB SensorData 테이블에 직접 저장

3. **알림 이력 조회**
   - 과거 알림 이력 확인
   - 알림 상태별 필터링

4. **통계 및 분석**
   - 센서 데이터 통계
   - 활동 패턴 분석
   - 최근 활동 타임라인

### 실행 방법
```powershell
cd dashboard
.\start_8503.ps1
```

### URL
http://localhost:8503

---

## 🎨 대시보드 2: 프론트엔드 V1 - 수동 제어 (포트 8504)

### 역할
시스템 아키텍처 시각화 및 수동 워크플로우 제어

### 주요 기능
1. **시스템 아키텍처 시각화**
   - AWS 서비스 구성도
   - 데이터 흐름 다이어그램

2. **수동 워크플로우 제어**
   - 4단계 워크플로우를 수동으로 제어
   - 각 단계별 버튼 클릭으로 진행
   - 실시간 상태 표시 (색상 변경)

3. **음성 재생**
   - AWS Polly 음성 선택 및 재생
   - 5가지 시나리오 음성 파일

4. **실시간 워크플로우 상태**
   - 센서 수집 → 낙상 감지 → 음성 확인 → 보호자 알림
   - 각 단계별 색상 표시 (초록/빨강/주황)

### 실행 방법
```powershell
cd dashboard
.\start_v2.ps1
```

### URL
http://localhost:8504

## 🎬 대시보드 3: 프론트엔드 V2 - 실시간 자동 데모 (포트 8505)

### 역할
전체 워크플로우를 자동으로 실행하는 실시간 데모 대시보드

### 주요 기능
1. **버튼 하나로 전체 자동 실행** ⭐
   - "▶️ 시나리오 자동 실행" 버튼 클릭
   - 전체 워크플로우가 자동으로 진행

2. **대시보드 1 연동** ⭐ 중요!
   - 대시보드 1에서 설정한 보호자 정보 자동 로드
   - 사용자 이름, 나이, 보호자 연락처 등
   - 실제 SMS를 설정된 번호로 발송

3. **자동 진행 흐름**
   - Step 1: 센서 데이터 수집 (3초) → 초록색
   - Step 2: 낙상 감지 (5초) → 빨간색
   - Step 3: AI 스피커 음성 확인 (5초) → 주황색 + 자동 음성 재생
   - Step 4: 보호자 알림 발송 (5초) → 실제 SMS 발송
   - Step 5: 완료 → 초록색

4. **실시간 로그**
   - 각 단계별 상세 로그 표시
   - 타임스탬프 포함
   - 성공/오류 상태 표시

5. **AWS Polly 음성 자동 재생**
   - 음성 확인 단계에서 자동으로 음성 생성 및 재생
   - Neural TTS (Seoyeon 음성)

6. **실제 SMS 발송**
   - AWS SNS를 통한 실제 SMS 발송
   - 대시보드 1에서 설정한 보호자 번호로 발송

### 실행 방법
```powershell
cd dashboard
.\start_v3.ps1
```

### URL
http://localhost:8505

## 📊 대시보드 간 데이터 흐름

```
대시보드 1 (백엔드/관리자)
    ↓
    보호자 정보 저장 (DynamoDB UserSettings)
    ↓
대시보드 3 (프론트엔드 실시간)
    ↓
    보호자 정보 자동 로드
    ↓
    실제 SMS 발송 (설정된 번호로)
```

### 중요 포인트
1. **대시보드 3를 사용하기 전에 대시보드 1에서 보호자 정보를 먼저 설정하세요!**
2. 대시보드 1에서 설정한 정보가 대시보드 3에서 자동으로 사용됩니다
3. SMS는 대시보드 1에서 설정한 실제 번호로 발송됩니다

## 🎯 사용 시나리오

### 시나리오 1: 시스템 초기 설정
1. 대시보드 1 실행 (8503)
2. Tab 4: Settings Management에서 보호자 정보 입력
3. "📞 보호자 연락처 저장" 클릭
4. 설정 완료!

### 시나리오 2: 수동 테스트
1. 대시보드 2 실행 (8504)
2. 각 단계별 버튼을 클릭하여 수동으로 진행
3. 워크플로우 상태 확인

### 시나리오 3: 자동 데모 (추천!)
1. 대시보드 1에서 보호자 정보 설정 (최초 1회)
2. 대시보드 3 실행 (8505)
3. "▶️ 시나리오 자동 실행" 버튼 클릭
4. 전체 워크플로우 자동 진행 확인
5. 실제 SMS 수신 확인!

## 🔍 트러블슈팅

### 대시보드 3에서 "보호자 정보 없음" 경고가 나올 때
→ 대시보드 1에서 보호자 정보를 먼저 설정하세요

### SMS가 발송되지 않을 때
1. AWS SNS 권한 확인
2. 대시보드 1에서 보호자 번호가 올바르게 설정되었는지 확인
3. 전화번호 형식 확인 (010-XXXX-XXXX)

### 포트 충돌 오류
- 각 대시보드는 다른 포트를 사용합니다 (8503, 8504, 8505)
- 이미 실행 중인 프로세스가 있는지 확인하세요
