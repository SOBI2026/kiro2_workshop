# 🏥 시니어 안심 케어 - 워크플로우 요약

## 📊 시스템 개요

독거 노인의 안전을 실시간으로 모니터링하고, 이상 징후 발생 시 자동으로 대응하는 AI 기반 시스템입니다.

---

## 🔄 4단계 워크플로우

### 1️⃣ 센서 데이터 수집
**목적**: 사용자의 활동 데이터를 실시간으로 수집

**센서 종류**:
- 🚶 **motion**: 동작 감지 센서 (거실, 침실, 화장실)
- 🚪 **door**: 문 개폐 센서 (현관문, 방문)
- 📱 **accelerometer**: 가속도 센서 (스마트폰, 웨어러블)
- 🌡️ **temperature**: 온도 센서 (실내 온도)

**데이터 흐름**:
```
센서 → API Gateway → Lambda (SensorDataProcessor) → DynamoDB
```

**저장 데이터**:
- userId, timestamp, deviceId, deviceType, sensorType, value
- lastActivityTime 자동 업데이트

---

### 2️⃣ 활동 부재 감지
**목적**: 이상 징후 자동 탐지

**감지 방법**:
1. **EventBridge**: 1분마다 InactivityDetector Lambda 실행
2. **임계값 체크**: lastActivityTime과 현재 시간 비교
3. **낙상 감지**: accelerometer > 10.0 (급격한 충격)
4. **활동 부재**: 설정된 시간(기본 120분) 이상 활동 없음

**알림 생성**:
```python
{
    "alertId": "uuid",
    "userId": "test-user-001",
    "alertType": "inactivity" or "fall_detected",
    "status": "voice_confirmation_pending",
    "createdAt": "2026-03-27T12:23:36",
    "lastActivityTime": "2026-03-27T10:00:00"
}
```

**상태 변화**:
- 정상 → 이상 징후 감지 → 알림 생성

---

### 3️⃣ AI 스피커 음성 확인
**목적**: 자동 안부 확인 및 오탐 방지

**프로세스**:
1. **AI 스피커 호출**: Alexa/Google Home/Clova 연동
2. **음성 질문**: "김영희님, 괜찮으세요? 응답해주세요."
3. **응답 대기**: 30초 타임아웃
4. **응답 분석**: 음성 인식 및 의미 분석

**시나리오**:

#### ✅ 시나리오 A: 정상 응답
```
사용자: "네, 괜찮아요. 걱정 마세요."
시스템: status → "confirmed_safe"
결과: 정상 모니터링 계속, 보호자 알림 없음
```

#### ⚠️ 시나리오 B: 응답 없음
```
시스템: 30초 타임아웃
시스템: status → "no_response"
결과: 보호자 알림 단계로 진행
```

#### 🆘 시나리오 C: 위급 응답
```
사용자: "도와주세요!" or "아파요!"
시스템: status → "emergency"
결과: 즉시 보호자 알림 + 119 자동 신고
```

---

### 4️⃣ 보호자 알림
**목적**: 보호자에게 긴급 상황 전달

**알림 채널**:
- 📱 **SMS**: 휴대폰 문자 메시지
- 📲 **푸시 알림**: 모바일 앱 알림
- 📧 **이메일**: 상세 리포트 포함

**알림 내용**:
```
🚨 긴급 알림

김영희님(75세)에게 이상 징후가 감지되었습니다.

- 낙상 의심 (가속도: 15.8)
- 음성 응답 없음
- 즉시 확인이 필요합니다

위치: 서울시 강남구 (자택)
시간: 2026-03-27 12:23:36
연락처: 010-1234-5678

[지금 확인하기] [위치 보기] [119 신고]
```

**재시도 로직**:
- 최대 3회 재시도
- 지수 백오프 (1분, 2분, 4분)
- DLQ (Dead Letter Queue)로 실패 메시지 저장

**상태 업데이트**:
```
no_response → notification_sent → resolved
```

## 🎮 대시보드 사용법

### 버전 1 (http://localhost:8503) - 기능 중심
**5개 탭**:
1. **실시간 모니터링**: 사용자 상태, 최근 활동 타임라인
2. **센서 데이터 전송**: 테스트 데이터 전송
3. **알림 이력**: 모든 알림 확인
4. **설정 관리**: 임계값, 타임아웃 설정
5. **통계**: 시간대별 활동 분포, 센서 타입별 분포

### 버전 2 (http://localhost:8504) - 아키텍처 뷰
**주요 기능**:
1. **시스템 아키텍처**: 4단계 프로세스 시각화
2. **실시간 워크플로우 상태**: 각 단계별 실시간 상태 표시
   - ✅ 정상 (초록색)
   - ⚠️ 경고 (빨간색)
   - ⏳ 진행중 (주황색)
   - ⏸️ 대기 (회색)
3. **워크플로우 시뮬레이션**: 버튼으로 각 단계 제어
   - 음성 응답 시뮬레이션
   - 보호자 알림 발송
   - 상황 종료
   - 워크플로우 초기화

## 🔧 기술 스택

### AWS 서비스
- **Lambda**: 7개 함수 (서버리스 컴퓨팅)
- **DynamoDB**: 3개 테이블 (NoSQL 데이터베이스)
- **API Gateway**: REST API (IAM 인증)
- **EventBridge**: 스케줄러 (1분마다 실행)
- **SNS/SQS**: 메시징 서비스
- **CloudWatch**: 로깅 및 모니터링
- **KMS**: 데이터 암호화
- **Secrets Manager**: 자격증명 관리

### 프레임워크 & 라이브러리
- **AWS SAM**: 인프라 as 코드
- **Python 3.12**: Lambda 런타임
- **Boto3**: AWS SDK
- **Streamlit**: 대시보드 UI
- **Plotly**: 데이터 시각화
- **Hypothesis**: Property-based testing

- **센서 데이터 처리**: < 100ms
